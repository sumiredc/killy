# Killy — プライバシーポリシー

このポリシーは、Killy のモバイル app（iOS と Android）、それがつなぐ Killy サーバー、サポートページのお問い合わせフォームに適用されます。どんなデータを扱い、何のために使い、誰が受け取り、どう消せるかを書きます。最終更新: 2026-11-22。この文書は英語版 `PRIVACY.md` の日本語訳で、正は英語版です。食い違ったときは英語版に従ってください。

Killy にはアカウントも広告も解析もありません。以下に書く目的以外で、データを販売することも共有することもありません。

## app が送るデータと目的

| データ | 目的 |
|---|---|
| app の初回起動時に Killy サーバーが作る、ランダムな device token | この端末を見分けるため。サーバーに保存するのは SHA-256 のハッシュだけで、token そのものは端末の安全な保管領域に残ります |
| 端末の push token（Apple または Google が Expo を通して発行する）。通知を許可した場合だけ | サーバーに新しいゾンビプロセスが現れたとき、通知を送るため |
| app 全体の通知スイッチと、サーバーごとの表示名と通知スイッチ | この端末で付けた名前でサーバーを表示し、求められたときだけ通知するため |
| 入力またはスキャンしたペアリングコード | この端末をサーバーにひも付けるため。コードは 1 回だけ使え、10 分で失効します |
| kill の要求: どのサーバーのどのプロセスか、ランダムな ID | そのサーバーのエージェントに、そのプロセスを止めるよう頼むため |

カメラは、`killy agent pair` が表示する QR コードを読むためだけに使います。画像は保存も送信もせず、読み取ったコードだけを使います。

app は言語の設定も端末に保存します。

## サーバーが保存するもの

Killy サーバーは、データベースに次を保存します。

- 端末ごとに、device token のハッシュ、あれば push token、通知スイッチ
- Killy エージェントを動かしている Linux サーバーごとに、エージェント token のハッシュとホスト名
- 端末とサーバーのひも付けと、ひも付けごとの表示名と通知スイッチ
- ゾンビを持つ親プロセスごとに、プロセス ID、開始時刻、最初に見つけた時刻、そして通知を送った端末。これらは、そのプロセスがゾンビを持たなくなった時点で削除します

メモリにだけ持ち、再起動で失うものは次のとおりです。各エージェントの最新の報告（ゾンビを持つ親プロセスのプロセス ID・開始時刻・コマンドラインと、ゾンビのプロセス ID）、ペアリングコード、リクエストの速さを制限するためのアドレスごとのリクエスト数。

Linux サーバー上のエージェントは、kill ごとの結果（ID、結果、回収したゾンビの数）を、そのサーバー上のファイルに残します。

## お問い合わせフォームが集めるデータ

サポートページ（<https://killy.sumire-sakamoto.co.jp/support/>）のお問い合わせフォームは、Google フォームです。次のことを尋ねます。

| データ | 目的 |
|---|---|
| メールアドレス | 返信するため |
| 名前（任意） | 返信で呼びかけるため |
| お問い合わせの種類 | 内容を振り分けるため |
| 端末（任意） | app の問題を再現するため |
| app のバージョン（任意） | app の問題を再現するため |
| サーバーの OS と CPU（任意） | エージェントの問題を再現するため |
| お問い合わせの内容 | 答えるため |

これらの回答は、返信と、データの削除の依頼への対応のためだけに使います。回答は Google がフォームの回答として保存します。フォームは Google のサイトで開きます。Killy の app・Killy サーバー・サポートページが、フォームにほかのものを送ることはありません。

## 他に受け取る相手

- **Expo、Apple、Google** が push 通知を届けます。受け取るのは、push token と通知の文面（ゾンビプロセスの数とサーバーの表示名）です。
- **Google** が、お問い合わせフォームの回答を保存し、入力した内容を受け取ります（上の節を参照）。
- **Cloudflare** が、app・エージェント・Killy サーバーの間のすべての通信を運び、各リクエストの送信元アドレスを見ます。
- Killy サーバーとその web サーバーは、リクエストのアドレスと時刻をログに記録することがあります。

## 公開デモ

この節は、Kiroween 2026 ハッカソンの審査員向けに作った build だけの話です。その build は、チームの staging の Killy サーバーにつながり、公開のデモサーバーを出します。ストアの製品版の app（App Store と Google Play）は production の Killy サーバーにつながり、デモはありません。デモに出るプロセスは、そのためだけにデモ機で作ったものです。デモに送った kill は、使っている全員に見えます。1 人が kill した親は、全員の画面から消えます。

## データを消す

- app でサーバーを削除する（設定 → サーバー → 削除）と、この端末のそのサーバーへのひも付けが、表示名と通知スイッチごと消えます。
- app の通知をオフにすると push が止まります。app をアンインストールすると、device token は使われなくなります。
- 端末の記録やサーバーの記録を Killy サーバーから消してほしいときは、サポートページ <https://killy.sumire-sakamoto.co.jp/support/> のお問い合わせフォームから依頼してください。フォームに書いた回答も、依頼があれば消します。
