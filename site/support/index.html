The Killy app shows the zombie processes of your Linux servers. Each server needs the Killy agent, which reports to the Killy server and signals a process only when your phone asks.Killy アプリは、Linux サーバーのゾンビプロセスを表示します。サーバーごとに Killy agent が必要です。agent は Killy サーバーに報告し、スマホから頼まれたときだけプロセスに信号を送ります。

Install the agentagent を入れる

Do this on each Linux server you want watched. The agent only connects out to the Killy server, so the server opens no inbound port.見張りたい Linux サーバーごとに行います。agent は Killy サーバーへ外向きにつなぐだけなので、サーバーに受け口は開きません。

Requirements必要な環境

  • Linux 5.3 or later (the agent signals through a pidfd)Linux 5.3 以降（agent は pidfd を通して信号を送ります）
  • amd64 or arm64amd64 または arm64
  • root, so that the agent can signal other users' processesroot 権限（agent が他のユーザーのプロセスに信号を送るため）
  • HTTPS access from the server to killy.sumire.pinkサーバーから killy.sumire.pink への HTTPS 接続

1. Download and check the binary1. バイナリを取得して確かめる

The commands pick the file for your CPU, compare it with the published checksum, and put it in /usr/local/bin. sha256sum -c prints OK when the file matches.コマンドは、CPU に合うファイルを選び、公開しているチェックサムと照合して、/usr/local/bin に置きます。ファイルが一致すると、sha256sum -c は OK と表示します。

$ arch=$(uname -m | sed 's/x86_64/amd64/; s/aarch64/arm64/')
$ curl -fLO "https://killy.sumire-sakamoto.co.jp/download/killy-linux-$arch"
$ curl -fLO https://killy.sumire-sakamoto.co.jp/download/SHA256SUMS
$ grep " killy-linux-$arch\$" SHA256SUMS | sha256sum -c -
$ sudo install -m 0755 "killy-linux-$arch" /usr/local/bin/killy

2. Pair the server2. サーバーをペアリングする

The command shows a 6-character code and a QR code. A code works once and expires after 10 minutes.コマンドが、6 文字のコードと QR コードを表示します。コードは 1 回だけ使え、10 分で失効します。

$ sudo killy agent pair --server https://killy.sumire.pink

In the app, open Settings, then Add server. Enter the code (or scan the QR code), optionally enter a name, and tap Add. Without a name, the server's hostname is used.アプリで、設定 → サーバーを追加を開きます。コードを入力（または QR コードを読み取り）し、必要なら名前を入力して、追加をタップします。名前を入れなければ、サーバーのホスト名になります。

3. Keep the agent running3. agent を常駐させる

The systemd unit starts killy agent run as root and restarts it when it stops. It needs the file that pair wrote, so enable it after pairing.systemd の unit は、killy agent run を root で起動し、止まれば再起動します。pair が書いたファイルが要るので、ペアリングのあとに有効にします。

$ sudo curl -fL -o /etc/systemd/system/killy-agent.service https://killy.sumire-sakamoto.co.jp/download/killy-agent.service
$ sudo systemctl daemon-reload
$ sudo systemctl enable --now killy-agent.service

4. Check the connection4. 接続を確かめる

In the app, open Settings, tap the server, and tap Check under Connection. The app shows "Connected" with the agent version when a command can reach the agent and come back.アプリで、設定を開き、サーバーをタップして、接続の「確認する」をタップします。命令が agent に届いて戻れるとき、アプリは agent のバージョンと一緒に「接続できました」と表示します。

The app showsアプリの表示What to do対処

To stop watching a server, open Settings, tap the server and remove it. The agent keeps running for other paired phones; to stop it, run sudo systemctl disable --now killy-agent.サーバーの見張りをやめるには、設定でサーバーをタップして削除します。ほかのペアリング済みのスマホのために agent は動き続けます。agent を止めるには、sudo systemctl disable --now killy-agent を実行します。

What Killy promisesKilly が守ること

Only SIGKILLSIGKILL だけ

Killy sends no other signal and runs no other command on your server.Killy は、ほかの信号を送らず、サーバーでほかのコマンドも実行しません。

Only the process you were shown見せたプロセスだけ

Right before signalling, the agent checks that the process still has the PID and start time shown in the app, and still has zombie children. A reused PID is not killed.信号を送る直前に、agent は、アプリに見せたものと同じ PID と開始時刻のプロセスで、まだゾンビの子がいることを確かめます。再利用された PID は kill しません。

Protected processes守られるプロセス

The agent never kills PID 1, itself or its own ancestors, whatever the Killy server asks.agent は、Killy サーバーに何を頼まれても、PID 1・自分自身・自分の祖先は kill しません。

Only your phoneペアリングしたスマホだけ

Only a phone paired with a server can see its zombies or send it a kill. The agent opens no inbound port.サーバーのゾンビを見られるのも、kill を送れるのも、そのサーバーとペアリングしたスマホだけです。agent は受け口を開きません。

Killy shows the server, PID and command line it will kill. Whether that parent is safe to kill is your decision. Killing a parent stops the work it does.Killy は、kill するサーバー・PID・コマンドラインを見せます。その親を kill してよいかの判断は、あなたのものです。親を kill すると、その親の仕事は止まります。

What the Killy server and the app keep is listed in the privacy policy.Killy サーバーとアプリが保存するものは、プライバシーポリシーに書いてあります。
